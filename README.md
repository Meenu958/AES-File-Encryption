# AES File Encryption and Decryption Tool

A Python-based cybersecurity project that provides a simple command-line tool for encrypting and decrypting files using password-based encryption.

## About the Project

The AES File Encryption and Decryption Tool is designed to demonstrate how cryptography can be used to protect files and sensitive data.

The user can select a file, provide a password, and encrypt the file. The encrypted file is stored separately and can later be decrypted using the correct password.

This project demonstrates practical concepts related to:

- File encryption
- File decryption
- Cryptography
- Data security
- Password-based protection
- Secure file handling

## Current Features

- Encrypt files
- Decrypt encrypted files
- Password-based file protection
- Separate folders for encrypted and decrypted files
- Simple command-line interface
- Error handling during encryption and decryption
- Password strength checker
## Technologies Used

- Python
- Cryptography library
- Fernet
- SHA-256
- Base64
- Linux / Kali Linux
